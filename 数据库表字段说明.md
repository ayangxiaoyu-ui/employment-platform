# 数据库表字段说明

数据库：`employment_platform`  
说明：以下字段定义根据 `employment_platform.sql` 的建表语句整理。

---

## 1. `sys_user`（系统用户表）


| 字段名         | 类型           | 约束/索引                        | 默认值                                                  | 字段说明                     |
| ----------- | ------------ | ---------------------------- | ---------------------------------------------------- | ------------------------ |
| id          | bigint(20)   | PK, AUTO_INCREMENT, NOT NULL | -                                                    | 主键ID                     |
| username    | varchar(50)  | NOT NULL, UK(`uk_username`)  | -                                                    | 用户名                      |
| password    | varchar(100) | NOT NULL                     | -                                                    | 密码（加密存储）                 |
| role        | varchar(20)  | NOT NULL                     | -                                                    | 角色：ADMIN/COMPANY/STUDENT |
| status      | int(1)       | NULL                         | 1                                                    | 状态：1正常，0禁用               |
| create_time | datetime(0)  | NULL                         | CURRENT_TIMESTAMP(0)                                 | 创建时间                     |
| update_time | datetime(0)  | NULL                         | CURRENT_TIMESTAMP(0), ON UPDATE CURRENT_TIMESTAMP(0) | 更新时间                     |


## 2. `student`（学生表）


| 字段名             | 类型           | 约束/索引                        | 默认值  | 字段说明             |
| --------------- | ------------ | ---------------------------- | ---- | ---------------- |
| id              | bigint(20)   | PK, AUTO_INCREMENT, NOT NULL | -    | 主键               |
| user_id         | bigint(20)   | NOT NULL, UK(`uk_user_id`)   | -    | 关联 `sys_user.id` |
| name            | varchar(50)  | NULL                         | NULL | 姓名               |
| gender          | varchar(10)  | NULL                         | NULL | 性别               |
| phone           | varchar(20)  | NULL                         | NULL | 联系电话             |
| email           | varchar(100) | NULL                         | NULL | 邮箱               |
| university      | varchar(100) | NULL                         | NULL | 毕业院校             |
| major           | varchar(100) | NULL                         | NULL | 专业               |
| graduation_year | int(4)       | NULL                         | NULL | 毕业年份             |
| avatar          | varchar(255) | NULL                         | NULL | 头像URL            |


## 3. `company`（企业表）


| 字段名            | 类型           | 约束/索引                        | 默认值  | 字段说明              |
| -------------- | ------------ | ---------------------------- | ---- | ----------------- |
| id             | bigint(20)   | PK, AUTO_INCREMENT, NOT NULL | -    | 主键                |
| user_id        | bigint(20)   | NOT NULL, UK(`uk_user_id`)   | -    | 关联 `sys_user.id`  |
| name           | varchar(100) | NOT NULL                     | -    | 企业名称              |
| description    | text         | NULL                         | NULL | 企业简介              |
| logo           | varchar(255) | NULL                         | NULL | 企业Logo            |
| address        | varchar(200) | NULL                         | NULL | 详细地址              |
| industry       | varchar(50)  | NULL                         | NULL | 所属行业              |
| scale          | varchar(50)  | NULL                         | NULL | 人员规模              |
| contact_person | varchar(50)  | NULL                         | NULL | 联系人               |
| contact_phone  | varchar(20)  | NULL                         | NULL | 联系电话              |
| status         | int(1)       | NULL                         | 0    | 审核状态：0待审核，1通过，2拒绝 |


## 4. `category`（分类字典表）


| 字段名       | 类型          | 约束/索引                        | 默认值 | 字段说明           |
| --------- | ----------- | ---------------------------- | --- | -------------- |
| id        | bigint(20)  | PK, AUTO_INCREMENT, NOT NULL | -   | 主键             |
| name      | varchar(50) | NOT NULL                     | -   | 分类名称           |
| type      | int(1)      | NULL                         | 1   | 类型：1职位分类，2行业分类 |
| parent_id | bigint(20)  | NULL                         | 0   | 父级ID（树结构）      |


## 5. `job`（职位表）


| 字段名          | 类型           | 约束/索引                        | 默认值                                                  | 字段说明         |
| ------------ | ------------ | ---------------------------- | ---------------------------------------------------- | ------------ |
| id           | bigint(20)   | PK, AUTO_INCREMENT, NOT NULL | -                                                    | 主键           |
| company_id   | bigint(20)   | NOT NULL                     | -                                                    | 发布企业ID       |
| title        | varchar(100) | NOT NULL                     | -                                                    | 职位名称         |
| category_id  | bigint(20)   | NULL                         | NULL                                                 | 职位分类ID       |
| description  | text         | NULL                         | NULL                                                 | 职位描述         |
| requirements | text         | NULL                         | NULL                                                 | 任职要求         |
| salary_min   | int(11)      | NULL                         | NULL                                                 | 最低薪资         |
| salary_max   | int(11)      | NULL                         | NULL                                                 | 最高薪资         |
| location     | varchar(100) | NULL                         | NULL                                                 | 工作地点         |
| status       | int(1)       | NULL                         | 1                                                    | 状态：1招聘中，0已下架 |
| create_time  | datetime(0)  | NULL                         | CURRENT_TIMESTAMP(0)                                 | 发布时间         |
| update_time  | datetime(0)  | NULL                         | CURRENT_TIMESTAMP(0), ON UPDATE CURRENT_TIMESTAMP(0) | 更新时间         |


## 6. `resume`（简历表）


| 字段名         | 类型           | 约束/索引                           | 默认值                                                  | 字段说明         |
| ----------- | ------------ | ------------------------------- | ---------------------------------------------------- | ------------ |
| id          | bigint(20)   | PK, AUTO_INCREMENT, NOT NULL    | -                                                    | 主键           |
| student_id  | bigint(20)   | NOT NULL, IDX(`idx_student_id`) | -                                                    | 关联学生ID       |
| title       | varchar(100) | NULL                            | 我的简历                                                 | 简历名称         |
| content     | text         | NULL                            | NULL                                                 | 简历详情（JSON）   |
| file_url    | varchar(255) | NULL                            | NULL                                                 | 附件简历URL      |
| type        | int(11)      | NULL                            | 2                                                    | 1在线简历，2附件简历  |
| is_public   | int(1)       | NULL                            | 1                                                    | 是否公开：1公开，0保密 |
| create_time | datetime(0)  | NULL                            | CURRENT_TIMESTAMP(0)                                 | 创建时间         |
| update_time | datetime(0)  | NULL                            | CURRENT_TIMESTAMP(0), ON UPDATE CURRENT_TIMESTAMP(0) | 更新时间         |


## 7. `application`（职位申请表）


| 字段名         | 类型          | 约束/索引                        | 默认值                  | 字段说明                         |
| ----------- | ----------- | ---------------------------- | -------------------- | ---------------------------- |
| id          | bigint(20)  | PK, AUTO_INCREMENT, NOT NULL | -                    | 主键                           |
| job_id      | bigint(20)  | NOT NULL                     | -                    | 职位ID                         |
| student_id  | bigint(20)  | NOT NULL                     | -                    | 学生ID                         |
| resume_id   | bigint(20)  | NOT NULL                     | -                    | 使用的简历ID                      |
| status      | int(1)      | NULL                         | 0                    | 状态：0待查看，1已查看，2面试邀请，3不合适，4已录用 |
| create_time | datetime(0) | NULL                         | CURRENT_TIMESTAMP(0) | 投递时间                         |


> 复合唯一约束：`uk_job_student(job_id, student_id)`，同一学生对同一职位只能投递一次。

## 8. `favorite`（职位收藏表）


| 字段名         | 类型          | 约束/索引                        | 默认值                  | 字段说明 |
| ----------- | ----------- | ---------------------------- | -------------------- | ---- |
| id          | bigint(20)  | PK, AUTO_INCREMENT, NOT NULL | -                    | 主键   |
| student_id  | bigint(20)  | NOT NULL                     | -                    | 学生ID |
| job_id      | bigint(20)  | NOT NULL                     | -                    | 职位ID |
| create_time | datetime(0) | NULL                         | CURRENT_TIMESTAMP(0) | 收藏时间 |


> 复合唯一约束：`uk_student_job(student_id, job_id)`，同一学生同一职位仅一条收藏记录。

## 9. `browsing_history`（浏览历史表）


| 字段名         | 类型          | 约束/索引                        | 默认值                                                  | 字段说明   |
| ----------- | ----------- | ---------------------------- | ---------------------------------------------------- | ------ |
| id          | bigint(20)  | PK, AUTO_INCREMENT, NOT NULL | -                                                    | 主键     |
| student_id  | bigint(20)  | NOT NULL                     | -                                                    | 学生ID   |
| job_id      | bigint(20)  | NOT NULL                     | -                                                    | 职位ID   |
| count       | int(11)     | NULL                         | 1                                                    | 浏览次数   |
| update_time | datetime(0) | NULL                         | CURRENT_TIMESTAMP(0), ON UPDATE CURRENT_TIMESTAMP(0) | 最后浏览时间 |


> 复合唯一约束：`uk_student_job(student_id, job_id)`，同一学生同一职位仅保留一条浏览记录。

## 10. `message`（站内消息表）


| 字段名         | 类型          | 约束/索引                         | 默认值                  | 字段说明                   |
| ----------- | ----------- | ----------------------------- | -------------------- | ---------------------- |
| id          | bigint(20)  | PK, AUTO_INCREMENT, NOT NULL  | -                    | 主键                     |
| sender_id   | bigint(20)  | NOT NULL                      | -                    | 发送者用户ID（`sys_user.id`） |
| receiver_id | bigint(20)  | NOT NULL, IDX(`idx_receiver`) | -                    | 接收者用户ID（`sys_user.id`） |
| content     | text        | NOT NULL                      | -                    | 消息内容                   |
| type        | int(1)      | NULL                          | 1                    | 类型：1普通消息，2面试通知，3系统通知   |
| is_read     | int(1)      | NULL                          | 0                    | 状态：0未读，1已读             |
| create_time | datetime(0) | NULL                          | CURRENT_TIMESTAMP(0) | 发送时间                   |


## 11. `guide`（就业指导表）


| 字段名         | 类型           | 约束/索引                        | 默认值                        | 字段说明                      |
| ----------- | ------------ | ---------------------------- | -------------------------- | ------------------------- |
| id          | bigint(20)   | PK, AUTO_INCREMENT, NOT NULL | -                          | 主键                        |
| user_id     | bigint(20)   | NULL                         | NULL                       | 发布者 `sys_user.id`（平台文章可空） |
| title       | varchar(200) | NOT NULL                     | -                          | 标题                        |
| description | varchar(500) | NULL                         | NULL                       | 简介                        |
| cover       | varchar(300) | NULL                         | /uploads/guide/default.jpg | 封面图                       |
| content     | longtext     | NULL                         | NULL                       | 内容（富文本）                   |
| view_count  | int(11)      | NULL                         | 0                          | 浏览量                       |
| create_time | datetime(0)  | NULL                         | CURRENT_TIMESTAMP(0)       | 发布时间                      |


## 12. `news`（新闻公告表）


| 字段名         | 类型           | 约束/索引                        | 默认值                  | 字段说明                      |
| ----------- | ------------ | ---------------------------- | -------------------- | ------------------------- |
| id          | bigint(20)   | PK, AUTO_INCREMENT, NOT NULL | -                    | 主键                        |
| title       | varchar(200) | NOT NULL                     | -                    | 标题                        |
| content     | longtext     | NULL                         | NULL                 | 内容                        |
| author_id   | bigint(20)   | NULL                         | NULL                 | 发布人ID（通常对应 `sys_user.id`） |
| view_count  | int(11)      | NULL                         | 0                    | 浏览量                       |
| create_time | datetime(0)  | NULL                         | CURRENT_TIMESTAMP(0) | 发布时间                      |
